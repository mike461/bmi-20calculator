## 📖 Overview
This application allows users to quickly calculate their BMI by entering their height and weight. It provides instant feedback on their health category (Underweight, Healthy, Overweight, or Obese) using standardized medical formulas.

### Why this matters:
* **User-Centric:** Built with instant validation so users don't have to click "Calculate" multiple times.
* **Responsive:** Fully optimized for mobile devices, tablets, and desktops.
* **Accessible:** Uses high-contrast colors and clear labeling for better accessibility.

---

## 🛠️ Technical Tech Stack
* **Frontend:** HTML5 (Semantic tags), CSS3 (Flexbox/Grid), JavaScript (ES6+)
* **Logic:** Real-time arithmetic processing using the standard formula: 
  $$BMI = \frac{weight(kg)}{height(m)^2}$$
* **Deployment:** GitHub Pages

---

## ✨ Key Features
* **Real-time Results:** Users see their BMI category update instantly as they type.
* **Dynamic Styling:** The background or text color changes based on the health result (e.g., Green for Healthy, Red for Warning).
